# nddspiro2
A package used to extract relevant spirometry data from XML files generated by ndd spirometry medical devices. This package relies on `xml2` for XML parsing. Contribution and modifications are welcome.

## Installation
Install through GitHub by using `remotes` package in R

```
remotes::install_github("njh51/nddspiro2")
```

## Use cases
```
library(nddspiro)
library(xml2)

doc <- xml2::read_xml(/path/ndd.xml)

# extract all relevant spirometry parameters
spiro_param <- read_spiro(doc, trace = 3)

# extract channel flow and volume
spiro_curve <- read_curve(doc, trace = 3)
```
